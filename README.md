## 🌐 Deploy to GitHub Pages

To publish this website directly on GitHub:

1. Create a new repository on GitHub (e.g. `ivy-website` or `<username>.github.io`).
2. Run the following commands in this directory:

```bash
git init
git add .
git commit -m "feat: initial Ivy showcase website with live countdown and team credits"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your site will be live at `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/` within seconds!
